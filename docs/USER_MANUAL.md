# TapFeet 大脚输入法 · 用户操作手册

> 专为全键盘手机（Q25 / Titan2 /Titan2 Elite 等）开发的 Android 中文输入法。本手册带你从零上手。

---

## 一、功能简介

TapFeet（大脚输入法）是给**带实体全键盘的安卓手机**做的输入法，主打「键盘上就能完成所有输入操作，眼睛不用离开按键」。


除了常规的拼音输入、词库管理，TapFeet 的看家本领都在物理键盘上：**底排按键直接选字(巨硬模式)、Alt 一键锁定、长按字母出符号、键盘触摸「飞字」手势、可自定义快捷键**。

---

## 二、基础操作

### 1. 启用输入法
- 首次使用可打开 大脚输入法 App 里的「设置向导」走一遍引导。


### 2. 输入法切换

- **Alt + 空格**：在已启用的输入法之间循环切换（默认键位，可在「设置 → 物理键盘」里改或解绑）。
- **点击状态栏输入法图标**：顶栏上显示当前输入法的按钮，点一下即切到下一个输入法。
- **Shift + 空格**：弹出系统「输入法选择器」，手动挑选要用的输入法。
- **拼音下 Shift 切中英文**：在拼音输入法里按 Shift 可直接切到英文上屏（再按切回中文），不必退出拼音模式。

> 前两条（Alt+空格、状态栏图标）切换的是 TapFeet 内部已启用的各输入法；Shift+空格调出的是系统级选择器，可在 TapFeet 与其他输入法之间选。

## 三、特色功能说明

### 1. 物理键盘选字（巨硬模式）


| 候选栏 | 好 ④ | 是 ② | **我 ①** | 你 ③ | 他 ⑤ |
|---|---|---|---|---|---|
| 黑莓 Q25 | 左 Shift | `0` | 空格 | SYM（右 Alt） | 右 Shift |
| Titan2 | 左 Shift | Control | 空格  | Tab | 右 Alt |
| Titan2 Elite | 左 Shift | 返回 | 空格 | Fn | 右 Shift |
| Titan2 Elite（改键后） | `0` | 返回 | 空格 | Ctrl | Fn |

> **Titan2 Elite 完整巨硬键位（非默认，需改键位映射）**
> Titan2 Elite 底排两端的 ⭕️（Home）与 ⬛️（多任务）是系统键，IME 默认收不到——系统层在窗口之前就把它们消费掉了，任何输入法都拿不到这两个键。要让它们参与选字，先在设备的「**系统设置 → 快捷键 → 按键设置**」里把这两个键改成可被 IME 识别的普通键：**⭕️ → `0`、⬛️ → `Ctrl`**。
> 改完后再到 TapFeet「设置 → 物理键盘 → 快捷键」即可套用下面这套完整巨硬布局：左 / 右 Shift 让位给翻页，中间五键铺满候选。



候选多于 5 个时要翻页：屏幕候选栏上自带「 `<` / `>`」按钮：

| 翻页 | 下一页 | 上一页 |
|---|---|---|
| 黑莓 Q25 | `$` | Alt + `$` |
| Titan2 | 屏幕按钮 `>` | 屏幕按钮 `<` |
| Titan2 Elite | Sym | Alt + Sym |
| Titan2 Elite（改键后）| 右Shift | 左Shift |
> ＊ Titan2 预设默认未绑定物理翻页键，翻页请点屏幕候选栏上的「上一页 / 下一页」按钮，或到「设置 → 物理键盘」自行绑定。



- 巨硬模式左右键按相对偏移选词，黑莓手感最顺；**普通模式**则按 1-2-3-4-5 线性排布、按键按顺序对应（设置 → 候选 → 候选栏排列模式 可切换）。
- **`Alt + 数字`**：直接选第 N 个候选（黑莓经典操作）。
- 以上所有按键绑定都可在「设置 → 物理键盘」里自行修改。

### 2. 键盘飞字（触摸面手势）

仅对**自带触摸面的键盘**有效（如 Titan2 Elite 的键盘触摸面），手指不用去够屏幕。

所有手势都在「**设置 → 物理键盘 → 飞字**」里：总开关 + 各手势子开关，另有翻页方向对调、灵敏度、误触防护时长可调。

| 手势 | 作用 |
|---|---|
| **上滑** | 选字——滑到哪个候选词就选哪个 |
| **左右滑** | 候选翻页（左 = 下一页、右 = 上一页，可在设置里对调） |
| **右上角起手左滑** | 退格删除：先删拼音，拼音没了再删已上屏文字（独立开关） |
| **无候选字时左右滑** | 移动光标（逐字；独立开关）：**按住不松手拖着走，光标实时跟手**，中途可反向 |
| **无候选字时上下滑** | 移动光标（逐行；独立开关，默认关——上下易误触）：同样拖着走实时跟手 |
| **Alt 按住或锁定后滑动** | 扩选文字（独立开关）：替代移动光标，同样拖着走实时扩选 |

- **右上角起手左滑**只在触摸面右上角起手才生效，其它位置左滑照常翻页，避免误删。
- **移动光标 / 扩选**要先滑过一段更长的距离才「开闸」（防误触），开闸后手指不抬起来继续移动就是连续跟手；快速轻甩一下则只走一格。
- 符号 / 表情 / 颜文字窗口开着时，左右滑改为**翻动该窗口**的页面。
- 所有手势音效与物理按键一致（同一条按键音管线）。
- 「误触防护时长」内刚敲过按键的触摸会被忽略——锁定 Alt 后稍停半拍再滑即可。

> 本机键盘若没有触摸面，收不到触摸事件、手势自然不触发，属正常。

### 3. Alt 锁定

模拟黑莓的「按住 Alt 打字」体验：

- **双击**锁定键（默认左 Alt）即可锁定 Alt 状态，之后每个按键都自动带 Alt，无需一直按住。
- 按 **Alt / 空格 / 回车** 任意一键解锁。
- 开启后还能用 **Alt + Del / 退格** 删除整行（终端 kill-line 手感）。
- 锁定键本身可在「设置 → 物理键盘 → Alt 行为」里改，也可以关掉这个功能。

### 4. 长按字母出键帽符号（黑莓风格）

开启后（设置 → 物理键盘 → 长按按键输入符号），**长按某个字母或数字键**，直接上屏键帽上印的那个符号（比如长按数字键出 `#`、长按字母出对应标点），不用去翻符号面板。长按触发时长也可调。

### 5. 符号 / 表情窗口快速输入

不想碰屏幕就能插符号、表情、颜文字？用 **Sym 键**（黑莓）或 **Fn 键**（Titan2 Elite 等带 Fn 键的机型）一键打开符号 / 表情 / 颜文字面板窗口：

- 窗口内含「符号 / 表情 / 颜文字」三个页签，窗口内可一键互切。
- 面板里的项目按**键盘形网格**排布（QWERTY / ASDF / ZXCV 三行），对应 26 个字母键位——按 **Q** 选第 1 行第 1 个、**A** 选第 2 行第 1 个、**Z** 选第 3 行第 1 个，依此类推，**全程不用触屏**。
- 窗口打开后，直接按对应字母键即选入并上屏；**翻页**复用候选翻页键（见「特色功能 · 物理键盘选字」里的翻页键）。
- 这个符号窗口键可在「设置 → 物理键盘」里改；与 `Fn + 字母`、`右Shift + 字母` 等快捷键组合互不冲突。

### 6. 自定义词组导入（从文本批量加词）

想把常用短语一次性灌进去？支持从文本导入：

1. 进入「设置 → 词库 → 自定义词组」。
2. 点「导入」，粘贴词组，**每行一条**。
3. 两种写法：
   - 带拼音和顺序：`nh,1=你好`（拼音 `nh`、顺序 `1`，顺序可省略）。
   - 纯中文：`你好` —— 系统自动补拼音。
   - `#` 开头的行为注释，会被忽略。
4. 下一步会显示预览（新增 / 跳过重复 / 失败各几条），确认后导入。

### 7. 用户词典与拼音词库

- **用户词典**：你打字过程中自动记住的临时词，可单独查看、滑动删除。
- **拼音词库**：管理基础词库、云拼音开关、模糊音等。
- 两者都在「设置 → 词库」分组下。

### 8. 声音方案

给按键配上不同的手感音效，命名走四字国风：

- **钢琴清音 / 电报嘀嗒 / 木鱼笃笃 / 算盘噼啪**，外加 **静音**。
- 在「设置 → 键盘 / 行为」相关声音项里选择；静音即完全无声。
- 物理键盘和键盘触摸手势的音效独立控制，关掉其中一个不影响另一个。

### 9. 输入特效

- 选词上屏时带**粒子特效**与连击（combo）计数，打字更有反馈感。
- 配合「飞字动画」一起开，键盘面手势选字会有飞字拖影。
- 总开关在输入特效设置里，想要极简干净手感可以一并关掉。

### 10. 快捷键自定义（动作绑定）

物理键盘除了选字，还能一键触发**动作**（编辑操作、开关）。入口：**设置 → 快捷键**，所有机型都有。

页内分两个页签，键位行双列排布：

| 页签 | 管什么 | 动作 |
|---|---|---|
| **编辑** | 文本编辑类 | 全选 / 复制 / 剪切 / 粘贴 / 全删 / 撤销操作 / 光标四向 / 选中四向（共 14 个） |
| **开关** | 输入法开关类 | 开关特效 / 开关音效 / 开关状态栏 / 开关飞字 / 切换候选排列 / 循环音效模式（共 6 个） |

#### 推荐键位

| 动作 | Titan 系（Titan2 / Titan2 Elite / 改键） | 黑莓 Q25 |
|---|---|---|
| 全选 | `Fn + A` | `右Shift + A` |
| 复制 | `Fn + C` | `右Shift + C` |
| 剪切 | `Fn + X` | `右Shift + X` |
| 粘贴 | `Fn + V` | `右Shift + V` |
| 全删 | `Fn + Q` | `右Shift + Q` |
| 撤销操作 | `Fn + Z` | `右Shift + Z` |
| 左移光标 | `Fn + S` | `右Shift + S` |
| 右移光标 | `Fn + F` | `右Shift + F` |
| 上移光标 | `Fn + E` | `右Shift + E` |
| 下移光标 | `Fn + D` | `右Shift + D` |
| 向上选中 | `Fn + U` | `右Shift + U` |
| 向下选中 | `Fn + J` | `右Shift + J` |
| 向左选中 | `Fn + H` | `右Shift + H` |
| 向右选中 | `Fn + K` | `右Shift + K` |
| 开关特效 / 开关音效 | `Sym + T` / `Sym + Y` | `右Shift + T` / `右Shift + Y` |
| 开关状态栏 / 开关飞字 | `Sym + B` / `Sym + L` | `右Shift + B` / `右Shift + L` |
| 切换候选排列 / 循环音效模式 | `Sym + P` / `Sym + M` | `右Shift + P` / `右Shift + M` |

> 光标簇 `S / F / E / D` 与选中簇 `U / J / H / K` 成对：**移动**用前者，**扩选区**用后者（选中簇的 H / K 是左右、U / J 是上下）。黑莓上两族都挂在**右 Shift** 上。

#### 改键：捕获窗口

点任意一行即可改键，弹出捕获窗口：

- **直接按物理键** → 绑定那个键（如单键、`Alt + 空格` 这类真修饰组合）。
- **用窗口里的按钮拼组合**：上一排 `Ctrl / Alt / Shift`（左右不分），下一排 `Fn / Sym / 左Alt / 右Alt / 左Shift / 右Shift`（可精确到侧别）。
- ⚠️ `Fn + 字母`、`右Shift + 字母` 这类前缀组合**必须**用下排按钮拼出来 —— 物理按住 Fn / Shift 再按字母，捕获窗口只会录到后一个键。
- 值右侧的删除按钮 = 解绑；最底部两个按钮作用于**整页**：「恢复推荐键位」按当前键盘预设重播全部推荐键位，「全部解绑」清空全部。

#### 与键盘预设联动

- 首次安装、**切换键盘预设**、点「恢复推荐键位」，都会按当前预设**整批写入**推荐键位 —— 自定义过的键位会被覆盖，和物理键位（候选/翻页那批）是同一个取舍。
- 换句话说：换了键盘预设（如 Titan2 Elite ⇄ 黑莓），快捷键会自动跟着换一整套，不用手动逐个改。

#### 冲突与优先级

- 同一个物理键若既绑了「选字 / 翻页」，又绑了这里的动作，**按键时动作优先**，设置页保存时会提示冲突。
- 冲突检测跨两个页签 + 「物理键盘」页的全部键位（它们抢的是同一个键盘）。

> **黑莓提示**：右 Shift 本身是「第 5 候选」键。按住右 Shift 触发快捷键时，按下那一下会先选第 5 个候选（按一下 vs 按住+字母是两种可区分的手势）。觉得抢手可到「设置 → 物理键盘」把候选 5 挪到别的键。

## 四、插件与输入方案（以中州韵为例）

TapFeet 通过**插件**扩展更多输入法引擎，启用对应插件即可在输入法里使用相应的输入方式。已内置多语种与工具插件（如日语、韩语、注音、粤语、越南语、泰语输入法，以及剪贴板过滤等）。

### 中州韵（Rime）插件

中州韵是开源输入法引擎，最大特点是**一套引擎、多套输入方案**——同一键盘可随时切换不同打字方式，方案、词库、简繁、标点都能自定义。启用后默认自带 6 套方案：

| 方案 | 说明 |
|---|---|
| 朙月拼音（luna_pinyin） | 全拼拼音 |
| 地球拼音（terra_pinyin） | 带声调标注的全拼 |
| 注音（bopomofo） | 台湾注音符号 |
| 仓颉五代（cangjie5） | 仓颉字形输入 |
| 速成五代（quick5） | 仓颉简化版 |
| 笔画（stroke） | 按笔画拆字 |

- **自定义**：方案、词库、简繁、标点都可通过配置文件增删扩展，高级玩家按需定制。

## 五、上手小贴士

- **刚开始用全键盘选字不顺手？** 先把「候选栏排列模式」设为「巨硬模式」，左右 Shift + `0` 基本能覆盖前 5 个候选，手感最接近黑莓原厂。
- **符号总找不到？** 开「长按字母出键帽符号」，长按即出，比切符号面板快得多。
- **想全键盘完成编辑？** `Fn + A / C / X / V / Z`（黑莓：`右Shift + 同名键`）即可全选 / 复制 / 剪切 / 粘贴 / 撤销；配合光标簇 `S / F / E / D` 移动、选中簇 `U / J / H / K` 扩选区，选字全程不用碰屏幕（见「特色功能 · 快捷键自定义」）。Titan2 Elite 这类带触摸面的键盘还可以**滑手势**：没出候选时四向滑移光标，双击 Alt 锁定后滑直接扩选（见「特色功能 · 键盘飞字」）。
- **打完字 Alt 卡住了？** 按一下 Alt 或空格就解锁；也可在设置里关掉 Alt 锁定。
- **想要安静？** 声音方案选「静音」，再关掉输入特效，就是一只安静的大脚。
